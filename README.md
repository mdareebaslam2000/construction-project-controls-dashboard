$200M Data Center Project Controls Dashboard
Project Overview
This portfolio project simulates project controls for a $200M hyperscale data center construction program and demonstrates Earned Value Management (EVM), cost forecasting, schedule performance analysis, WBS-based cost control, and executive reporting.
Note: This is a simulated portfolio case study created for educational and professional demonstration purposes.

Project Financial Structure
- Total Project Authorization: $200.0M
- Performance Measurement Baseline (BAC / PMB): $182.0M
- Management Reserve: $18.0M
- Project Duration: 24 months

Executive Interpretation
At Month 10, the project is behind baseline schedule and experiencing cost pressure.
- CPI = 0.95: the project is earning approximately $0.95 of budgeted value for every $1.00 spent.
- SPI = 0.91: earned progress is approximately 91% of planned progress.
- Current cost efficiency projects an EAC of approximately $198.7M, implying a forecast overrun of approximately $16.7M against the $182M performance baseline.
- The largest cost and schedule pressure is concentrated in Electrical and Mechanical / HVAC.
Key EVM Formulas
- PV = BAC × Planned % Complete
- EV = BAC × Actual % Complete
- CV = EV − AC
- SV = EV − PV
- CPI = EV / AC
- SPI = EV / PV
- EAC = BAC / CPI
- ETC = EAC − AC
- VAC = BAC − EAC

Portfolio Takeaway
This case study demonstrates how project controls metrics can be used to answer three core management questions:
1. Where should the project be today? — Planned Value
2. Where is the project actually today? — Earned Value and Actual Cost
3. Where is the project likely to finish? — EAC, ETC, and VAC
